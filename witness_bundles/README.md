# Measured full-history evidence bundles

**Article:** Results and Analysis — Measured Full-History Bundles

## Objective

Measure the serialised size of full-history evidence bundles and the cost of
verifying them, replacing the field-table estimate in the submitted
manuscript.

## Procedure

Bundles generated by the deployed implementation for 12 history prefixes on
seven hosts, giving 84 bundles. Sizes are exact serialised lengths.
Verification timings are the median of 30 warm-process calls with fresh
verifier state per host and prefix, excluding file I/O and parameter
loading. Prefixes include different recovery scenarios; replicas and
repeated calls are not independent deployments.

## Provenance

Each run directory contains `provenance.json` recording the frozen core file
hashes, the Python version, the host, and the effective parameters for that
run. Those hashes can be checked against `CODE_SHA256.txt` at the repository
root.

## What these records support

This campaign supports the byte-accounting table and the size/verification-cost figure. It is not evidence for any other claim in
the article.
