# Predeclared look-ahead withholding study

**Article:** Results and Analysis — Audited Look-Ahead Withholding Contrasts

## Objective

Contrast declared withholding strategies against a no-suppression arm under
a predeclared design, with no seed replacement and no pooling across
matrices.

## Procedure

Thirty-six blocks and 144 arms over 12 seeds, requiring 73 to 204 rounds
each and yielding 16,644 completed arm-round records. Every arm had 16
eligible opportunities; the N arm spent zero and each F, C and L arm
suppressed exactly four proposals, giving 432 actual suppressions. Every
suppressed round recovered in view 1.

This campaign predates the addition of consensus_v3.py and linked.py; see
the code note in the repository README.
